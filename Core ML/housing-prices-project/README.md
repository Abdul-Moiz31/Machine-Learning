# Housing prices — practice project (synthetic)

Notebook: [`housing.ipynb`](housing.ipynb)  
Data: [`housing-sample.csv`](housing-sample.csv)

The CSV is **synthetic** (random-ish process with a simple price formula). It is not real market data—only for drills that mirror the insurance workflow: EDA, encoding, buckets, Pearson vs **`price`**, chi-square vs price quartiles, scaling, then **`final_df`**.

Open the notebook from this folder so `pd.read_csv("housing-sample.csv")` works without path tweaks.
