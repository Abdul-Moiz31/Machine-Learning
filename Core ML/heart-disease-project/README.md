# Heart disease — practice project

Notebook: [`heart.ipynb`](heart.ipynb)  
Data: [`heart.csv`](heart.csv)

Tabular clinical-style features with a binary target **`HeartDisease`** (0/1). The notebook follows the same Core ML workflow as insurance and housing: EDA, encodings, **`pd.cut`** age bands, **`StandardScaler`**, Pearson and chi-square screens, then **`final_df`**.

Educational use only—not for diagnosis.

See the parent [`Core ML README`](../README.md) for concept explanations.
